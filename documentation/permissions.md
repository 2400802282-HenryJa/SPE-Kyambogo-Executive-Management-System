# Permissions (v0.1)

| Action | Who |
|---|---|
| Log in / view dashboard and projects | Any active user |
| Create a project | Any logged-in user (to be tightened in v0.2) |
| Edit a project | Superuser, the project owner, or the head of the project's department |
| Add milestones/tasks, manage users and departments | Admin site (staff users) |

Planned: separate read-only access for President/VP/CAO across all departments, and per-module permissions.
